# Orbit : versions Android

Versions publiées de l'appli Android Orbit, pour téléphone et TV. Chaque version contient ses nouveautés et l'APK.

- **Installer** : ouvrir la [dernière version](../../releases/latest) sur l'appareil, télécharger `orbit-x.y.z.apk` et l'ouvrir. Android demande d'autoriser l'installation d'applications inconnues pour le navigateur ou l'appli Fichiers.
- **Mettre à jour** : rien à faire. Au lancement, l'appli affiche les nouveautés de la nouvelle version. **Mettre à jour** la télécharge, vérifie le fichier et ouvre l'installateur. Tes données sont conservées.

Chaque version indique aussi l'empreinte SHA-256 de l'APK.
