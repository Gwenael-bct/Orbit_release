# Orbit : versions Android et iPhone

Versions publiées de l'appli Orbit. Chaque version contient ses nouveautés, l'APK Android et l'`.ipa` iPhone.

## Android (téléphone ou TV)

- **Installer** : ouvrir la [dernière version](../../releases/latest) sur l'appareil, télécharger `orbit-x.y.z.apk` et l'ouvrir. Android demande d'autoriser l'installation d'applications inconnues pour le navigateur ou l'appli Fichiers.
- **Mettre à jour** : rien à faire. Au lancement, l'appli affiche les nouveautés de la nouvelle version. **Mettre à jour** la télécharge, vérifie le fichier et ouvre l'installateur. Tes données sont conservées.

## iPhone

L'`.ipa` n'est pas signé : il s'installe avec [SideStore](https://sidestore.io) et ton identifiant Apple.

- **Installer** : ouvrir la [dernière version](../../releases/latest) dans Safari, télécharger `orbit-x.y.z.ipa`, puis **Partager** > **SideStore**.
- **Mettre à jour** : au lancement, l'appli affiche les nouveautés. **Télécharger** ouvre la page de la version : installer le nouvel `.ipa` de la même façon, par-dessus l'ancien (données conservées).
- SideStore re-signe l'appli tous les 7 jours (limite d'un compte Apple gratuit).

Chaque version indique aussi l'empreinte SHA-256 de l'APK.
