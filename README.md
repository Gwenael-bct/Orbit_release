# Orbit : versions Android

Versions publiées de l'appli Android Orbit.

- **Installer** : télécharger le fichier `orbit-x.y.z.apk` de la [dernière version](../../releases/latest), puis l'ouvrir sur le téléphone ou la TV.
- **Mettre à jour** : l'appli prévient d'elle-même quand une nouvelle version est disponible.

Chaque version est accompagnée de ses notes et de l'empreinte SHA-256 de l'APK.
